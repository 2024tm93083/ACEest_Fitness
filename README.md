# ACEest Fitness and Gym – DevOps Assignment
Flask-based fitness and gym management application demonstrating DevOps practices including version control, unit testing with Pytest, containerization with Docker, and automated CI/CD using GitHub Actions.

This repository contains a **Flask web application** built as part of my M.Tech coursework on *Introduction to DevOps*.  
The project demonstrates **end-to-end DevOps practices** including application development, version control, automated testing, containerization, and CI/CD pipeline setup.

---

## 🚀 Project Overview
The application is a simple **fitness and gym management system** that allows users to:
- Add workouts with duration  
- View logged workouts  

The primary focus of the project is not the complexity of the app itself, but the integration of DevOps principles for reliable and automated delivery.
